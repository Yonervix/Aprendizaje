# Plan de Estudio - Programación

**Objetivo:** llegar al proyecto universitario (Node, React, Django, Angular, Ionic) con base sólida en JavaScript.

**Ritmo:** ~2h/día, 8-10 semanas total.

**Regla de oro:** NO pasar a la siguiente fase hasta dominar la anterior. Cada fase usa lo aprendido antes.

---

## Fase 0: Fundamentos JS puro (Días 1-7)
Temas:
- Variables y tipos: `let`, `const`, números, strings, booleanos, `null`, `undefined`
- Operadores: aritmética, comparación, lógica
- Condicionales: `if/else`, `switch`, ternario
- Bucles: `for`, `while`, `forEach`
- Funciones: `function`, arrow functions, parámetros, `return`
- Arrays: push, map, filter, find, reduce
- Objetos: crear, acceder, modificar, destructuring
- Strings: template literals, métodos comunes

**Ejercicio final:** "gestor de tareas" en consola (agregar, listar, eliminar).

## Fase 1: JS esencial para trabajo real (Semana 2-3)
Temas:
- `async/await` y promesas (fetch a API pública)
- Módulos: `import` / `export`
- Manejo de errores: `try/catch`
- DOM (básico): seleccionar elementos, eventos, crear elementos

**Ejercicio:** página que cargue datos de una API (ej: pokeapi.co) y los muestre.

## Fase 2: Node.js + Express (Semana 4-5)
Temas:
- Correr JS con Node (`node archivo.js`)
- npm (`npm init`, instalar paquetes)
- Express: servidor, rutas GET/POST
- JSON: recibir y responder
- Variables de entorno (`.env`)

**Ejercicio:** API de tareas (GET lista, POST crear). Conectar frontend de Fase 1.

## Fase 3: React (Semana 6-8)
Temas:
- Componentes: función, `props`
- Estado: `useState`
- Efectos: `useEffect` (llamar a la API)
- Listas y condicionales: `.map()`, ternarios
- Eventos: onClick, forms

**Ejercicio:** gestor de tareas en React conectado a la API de Node.

## Fase 4: Proyecto integrado (Semana 9-10)
CRUD completo: React (front) + Node/Express (back) + SQLite.

## Fase 5: Django y Python (después del CRUD)
Conceptos ya conocidos (rutas, vistas, modelos), solo cambia sintaxis.

## Fase 6: Angular + Ionic (al final)
TypeScript + arquitectura. Con JS sólido, TS se aprende rápido.

---

## Reglas diarias
1. 2h todos los días (no 8h un día sí y 3 no)
2. Cero tutoriales pasivos: escribir todo y verificar que funcione
3. Si algo no funciona en 20 min, buscar en Google/documentación
4. Cada fin de semana, repetir el ejercicio de la semana sin mirar
5. Usar siempre lo aprendido antes

## Recursos
- freeCodeCamp (ejercicios interactivos)
- JavaScript.info
- MDN (documentación)
